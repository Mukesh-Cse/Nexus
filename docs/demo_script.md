# Demo script

## Before presenting

On your own laptop, install requirements, run validation and normal UI smoke tests, then start Streamlit. Open every page and check the graph visually. Refresh public sources if networking permits, otherwise keep the visible snapshot mode. Open docs/known_limitations.md and the exact test reports.

## Four-minute demonstration

0:00 — Problem: “Useful innovation connections are spread across company pages, research and funding sources. NEXUS makes the reasoning and evidence inspectable.”

0:30 — Company DNA: Select Baltic Offshore. Show sourced subsea operations/ROV capabilities and their links. Explain that these are public self-reports, not independently audited facts.

1:00 — Refinement: Add a public innovation priority. Save and point to the revision. Interests influence ranking but do not become technical capabilities.

1:30 — Combination: Inspect a pair/triple. Explain one input/output or security dependency. Show C/O/R/E, missing capabilities and coverage. State: “This is an unvalidated hypothesis, not an existing partnership.”

2:15 — Graph and radar: Open a capability node and a source. Review the Vinnova record's deadline, retrieval date and unconfirmed eligibility. Switch to Cleura to show a different perspective.

3:00 — Blueprint: Export Markdown. Describe the proposed isolated first experiment and what would be measured; no prototype outcome is claimed.

3:30 — Evidence: Show actual core/UI test reports, the synthetic benchmark label and failed live checks. Ask for a supervised partner pilot and independent recommendation ratings.

## Short pitch

“NEXUS connects complementary capabilities rather than merely finding similar companies. It builds a source-linked path from company knowledge to a testable innovation hypothesis, supporting research, possible funding and the first experiment. Our prototype keeps uncertainty visible so people can decide whether the connection is worth exploring.”

## Offline backup

Keep the included source snapshots and docs/sample_blueprint.md. Avoid a live refresh when the connection is unreliable. Explain exactly when sources were checked. If Streamlit cannot run, walk through the exported Markdown and architecture as a backup; do not portray the document as a running application.
