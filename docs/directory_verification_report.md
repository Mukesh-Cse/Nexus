# Directory integration verification

The expanded public listing reached 56 cards after counts 16, 32, 48 and 56, with Load More absent at the end. Related profile links contained the same 56 canonical URLs. This is coverage of the observed public listing, not a census of the wider ecosystem.

All 55 supplied audited seed organisations are retained. Energimyndigheten was added. Hundtjänst Blekinge's source URL was reconciled with the live /hundtjanst-blekinge-ab/ URL; the old URL and source history remain recorded. No organisation was removed.

All 56 profile pages were retrieved successfully across an initial attempt and targeted retries. The only missing core attribute is DNV Cyber's employee range. No employee counts, founding years, addresses, contact details or individual member/partner classes were guessed.

Original Swedish descriptions are kept. Each field has its exact official profile URL, retrieval time and source excerpt. Supplied seed facts and previous sources remain in the original seed and per-record source history. Capability categories and application domains are labelled deterministic mappings, not company-validated facts.

The UI adds a Member Directory page with search, published-location filters and a Blekinge filter. Company DNA shows verification state, missing fields and per-field sources. Equally scored partner suggestions prefer shared published cities, then shared Blekinge locations. This tie-break does not alter the C/O/R/E score formula.

The core fixture remains the original four-company dataset for reproducible comparisons; separate integration checks verify the full directory. Browser crawl was executed through CUA. The included crawler can refresh profiles from the recorded listing, or independently expand a new listing with optional Playwright. Static HTML alone cannot establish completion.

Company login, persistent hosted tenant storage, live event ingestion, Ymner retrieval and broad semantic models are still separate unfinished work; they are not delivered by this directory update.
